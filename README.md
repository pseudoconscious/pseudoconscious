# PseudoConscious Inc.

PseudoConscious Inc. is a Canadian company that supports open-source research in artificial intelligence. Our interests include large language models, AI agents, agent harnesses, and benchmarking. Our current work focuses on state-based agents and their harnesses, with taskless agents as one part of that research.

## Research

- [ResidentBench](https://www.pseudoconscious.com/residentbench/): A proof-of-concept study of how ten language model configurations used tools in five simulated scenarios without an assigned task. Supported by PseudoConscious Inc. ([preprint](https://www.preprints.org/manuscript/202611.0441/v2), [code and results](https://github.com/frdfm/frdfm-paper-residentbench-code))

## Projects

- [PseudoAgent](https://github.com/pseudoconscious/pseudoagent): A state-driven harness for AI agents.
- [PseudoChat](https://github.com/pseudoconscious/pseudochat): A chat application built on PseudoAgent.
